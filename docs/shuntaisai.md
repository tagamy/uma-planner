# 育成シナリオ「朋、史解き ―午式駿大祭―」システム・攻略仕様まとめ

育成ウマ娘の新シナリオ「朋、史解き ―午式駿大祭―（ごしきしゅんたいさい）」のシステム、データ一覧、および攻略のポイントを整理してまとめました。

## シナリオの基本情報とステータス上限

12年に一度の大祭「午式駿大祭」の成功を目指し、5つの演目（スピード[流鏑馬]・スタミナ[神旗争奪戦]・パワー[納舞]・根性[大曳神輿]・賢さ[飛駆]）の稽古と「教え」「教え転成」を通じてウマ娘を育成するシナリオです。最高峰の「LGランク」育成に対応しています。

### 解放ステータス上限

| スピード | スタミナ | パワー | 根性 | 賢さ |
| :---: | :---: | :---: | :---: | :---: |
| **2,200** | **1,850** | **1,800** | **1,700** | **1,800** |

## 【最重要】編成の絶対ルール：サポートカード「5種類以上のタイプ」

デッキ内のサポートカードタイプが**5種類未満**だと、シナリオ固有の超強力ボーナスである以下の2つが**発動しません**。
* **スキルPtトレーニング効果**
* **獲得上限アップ**

> **注意**: スピ3＋賢さ2＋友人などの偏った編成はNG。必ず5種類以上のタイプ（例：スピ2＋スタ1＋パワ1＋賢1＋友人 など）を散らして編成する必要があります。

## 「教え」のセット時期（全6回）と「教え転成」の仕組み

### 1. 教えの転成ルール
* **ジュニア級終了時（12月後半終了時）**:
  * 初期の5つの教え（`絆`・`得意率`・`ヒント`・`助力`・`体力`）のうち、**2つの教えを「特化の教え」「研鑽の教え」に転成**します。
  * **転成しなかった残りの3つの教えは、そのままクラシック級で使います。**
* **クラシック級終了時（12月後半終了時）**:
  * 残っていた未転成の**3つの教えを「協力の教え」「不屈の教え」「両道の教え」に転成**します。
  * **ジュニア級終了時に転成した2つの教え（`特化`・`研鑽`）は、そのままシニア級でも使います。**

### 2. どの練習にどの教えをセットするか選択できる時期（全6回）
1. **① ジュニア級 デビュー前**（育成開始3ターン目：初期5種をセット）
2. **② ジュニア級 デビュー後**（7月前半・駿大祭合宿前：初期5種を付け替え）
3. **③ ジュニア級 12月後半終了時**（★2つの教えを `特化`・`研鑽` に転成！未転成の3つと合わせた5個をセット）
4. **④ クラシック級 6月後半終了時**（7月前半・夏合宿前：`特化`・`研鑽` ＋ 未転成3つを付け替え）
5. **⑤ クラシック級 12月後半終了時**（★残り3つの教えを `協力`・`不屈`・`両道` に転成！全5種の転成教えをセット）
6. **⑥ シニア級 6月後半終了時**（7月前半・夏合宿前：全5種の転成教えを最終付け替え）

## 「教え」と「教え転成」完全データバンク

### ① 初期の5種と転成時の永続引き継ぎ効果

初期に授かる基本の5つの教えは、転成すると**「転成効果」としてその転成先の教えに永続で引き継がれます**。

| 教えの名前 | 主な基本効果 | 転成時に引き継がれる永続「転成効果」 |
| :--- | :--- | :--- |
| **絆の教え** | 絆ゲージ上昇量UP / 演目稽古のメイン能力UP | **夏合宿中に担当サポカが追加で＋1人出現！** |
| **得意率の教え** | 得意練習に出現しやすくなる | **演目稽古に友情ボーナスが乗る！** |
| **ヒントの教え** | ヒント（！）の発生率UP | **演目稽古時のヒント獲得数＋1！** |
| **助力の教え** | 友情非発生時のトレ効果UP | **演目稽古で「助力の支え（トレ効果UP）」獲得！** |
| **体力の教え** | 演目稽古の体力消費量ダウン | **演目稽古の体力消費ダウンがずっと継続！** |
